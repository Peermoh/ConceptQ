Strings: words your code can hold

Tap play. Nibb will explain strings on the board, out loud.
A string is any text in your program, like the title on a book. Three ideas, then we test them.

1Text goes inside quotes

Quotes tell Python "this is text, not a command." Single or double quotes both work.

title = "Python" print(title) # shows: Python

2The + sign glues strings

Joining strings is called concatenation. Python adds nothing in between, not even a space.

print("Book" + "Club") # shows: BookClub

3len() counts characters

len() gives back a number: how many characters are in the string. Spaces count too.

print(len("book")) # shows: 4
