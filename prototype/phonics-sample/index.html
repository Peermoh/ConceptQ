Grammar questions are made fresh too

Each question type draws from a bank of words, names and places, so the same lesson gives a different quiz every time. A few live examples (in the real lessons Nibb reads them aloud):

  • Phonics: a bank of about 300 picture words, grouped by the sounds they use, so a question only uses sounds the child has met.
  • Grammar: word banks for each rule (nouns with a/an, plurals, past tenses, adjectives, pronouns) and sentence frames with changing names, places and things.
  • Reading: several short stories per lesson; each quiz picks one and asks who, where and why about it.
  • Checked: like the Python quizzes, every generator is tested thousands of times by a script so no question has two right answers.
