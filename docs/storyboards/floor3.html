Floor 3 storyboard

The house has two floors and a roof. Advanced turns the roof space into a third floor (a loft) and makes the whole house smart. It is built the way a real loft conversion is: workshop, safety scaffolding, deliveries, dormer windows, floor and stairs, wiring, furniture, a lift, smart switches, an archive room, inspection, solar panels, then the control room. Covers PCAP sections 1–6.

Four choices to confirm before I write lessons
  1. Split classes into two lessons (recommended). Classes are the heart of PCAP: blueprints and objects first, then class vs instance variables. That makes 13 lessons plus the Master Builder challenge.
  2. No second crane. The roof stays on. Dormer windows open up the roof space, which is how real lofts are built. The basement in the curriculum doc moves into the loft as an archive room, because digging under a finished house is not logical.
  3. Git and AI lessons are simulations in the app: commits, branches and an AI suggestion to check are acted out on screen. Nothing needs installing.
  4. Garage project: a smart-home dashboard that reads sensor readings from a file, uses classes for each device, and has tests. It replaces the weather app, because internet APIs come in Expert.
