# Old one-off check scripts

These were written while building earlier features. Most take screenshots for a design review and check nothing,
and they no longer match the app (for example the welcome tour now covers the screen, and `check_quizzes.js`
cut code out of the page in a way that broke when the page changed).

They are kept for reference only. The maintained tests are in `../../tests` (run `node tests/run.js`).
