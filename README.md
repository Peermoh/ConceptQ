# ConceptQ

A learning app where Nibb, a friendly robot teacher, explains a concept on a chalkboard,
asks questions, and explains why a wrong answer is wrong. Each topic you finish builds
part of your house.

- Design: [`docs/superpowers/specs/2026-11-15-conceptq-design.md`](docs/superpowers/specs/2026-11-15-conceptq-design.md)
- Python curriculum (checked against PCEP-30-03, PCAP-31-04 and the official tutorial): [`docs/curriculum/python.md`](docs/curriculum/python.md)
- Clickable prototype: open [`prototype/index.html`](prototype/index.html) in a browser

Phase 1 is Python Beginner (the ground floor).
